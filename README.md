# Relay Room Thermal and Solar Simulator

Run with `pip install -r requirements.txt` and `streamlit run app.py`.

Models roof, walls, windows, doors, solar gains, infiltration sensible/latent cooling and equipment. Displays an **illustrative temperature gradient**, relative-humidity sweeps, envelope alternatives and hourly AC/PV economics. The spatial visualization is **not CFD**, weather is synthetic, and 365-day extrapolation is illustrative. Use verified 8760-hour insolation and hourly tariffs before procuring PV. Confirm cooling redundancy, permissible relay-end temperatures and signalling electrical safety with the responsible railway engineers.
